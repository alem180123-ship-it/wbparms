# Видео-пайплайн: белая сцена, рамки, субтитры по словам

Собирает вертикальный ролик 1080×1920 из закадрового голоса исходного видео.
Картинка исходника заменяется белым фоном с картинками в рамках, звук
остаётся, сверху русские субтитры по словам. Нежные сцены — курсив и лепестки,
жёсткие — заглавные буквы, уголки-скобки и росчерки.

## Быстрый старт

```bash
cd video-pipeline
./setup.sh                      # один раз: модели речи, шрифты, Python-пакеты
cp ~/pictures/*.jpg img/        # картинки, на которые ссылается build_data.py
./make.sh source.mp4 out/final.mp4
```

Нужны `ffmpeg`, Python 3, Node и Playwright с Chromium (в облачных сессиях
Claude Code всё это уже есть).

## Этапы

| Файл | Что делает |
|---|---|
| `energy.py` | огибающая громкости по кадрам → `work/energy.json` |
| `transcribe_sherpa.py` | Whisper turbo (sherpa-onnx) с разбивкой по паузам → `work/segments.json` |
| `align.py` | тайминги каждого слова от русской модели zipformer, применяет `corrections.json` → `work/words.json` |
| `build_data.py` | **сцены** (время, картинка, настроение, наезд камеры) и разбивка субтитров на строки → `work/data.json` |
| `stage.html` | вся графика: кадр считается как функция от времени `t` |
| `render.mjs` | Chromium рисует кадры, они передаются в ffmpeg → `work/video_only.mp4` |

## Под новое видео

1. Запустить `make.sh` один раз, прочитать `work/segments.json`.
2. Вписать ошибки распознавания в `corrections.json` (`"как распознано": "как надо"`).
3. Переписать список `S` в `build_data.py`: время начала сцены, `soft`/`hard`,
   картинка, направление въезда, крупный план (`face(zoom_from, zoom_to, x, y)`).
4. Проверить отдельные кадры: `node render.mjs --stills 1.0,12.5,40` → `work/still_*.png`.
5. Снова запустить `make.sh`.

Модели берутся из GitHub-релизов sherpa-onnx, потому что в облачном окружении
Hugging Face может быть закрыт. Рендер 80 секунд занимает около 11 минут
на 4 ядрах.
